# Security policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Things like a packet that crashes or lags a server, lets a player pick up or throw what they shouldn't, or damages
other players' worlds. Please **don't open a public issue** for these.

Report it privately instead: [Report a vulnerability](https://github.com/SafetImamovic/ThrowableMobs/security/advisories/new)
(the Security tab → "Report a vulnerability"). Include the Minecraft, loader and Throwable Mobs versions, the steps to
reproduce, and what an attacker can do with it.

This is a hobby project, so replies are best effort, usually within a week. Once it's fixed and released, the advisory
is published with credit to you, unless you'd rather stay anonymous.
